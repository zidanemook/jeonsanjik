# 제79회 심화 1~10번 상세 해설

이 문서는 v24 당시의 검토 기록입니다. 현재 범위는 [v25 최근 3회 해설 검토](HANNEUNG-EXPLANATIONS-RECENT-ROUNDS-2026-09-10.md)를 확인하세요.

배포 v24. 기존 공식 기출 1,149문항 중 **제79회 1~10번만** 상세 해설을 추가했다. 다른 1,139문항은 공식 정답·배점만 제공한다. 총 문항 수, 정답, 배점, 원문 이미지와 기존 풀이 식별자는 그대로다.

## 구성과 근거

각 해설은 지문 단서 → 정답 이유 → 보기 5개의 차이 → 기억 연결 → 확인한 자료 순서다. 기관 원문을 대조해 직접 작성했으며 교과서나 해설 페이지를 통째로 전재하지 않았다. 원문 링크와 확인일을 해설에 포함하여 풀이 기록에도 함께 남긴다. 국사편찬위원회가 제공하는 집필자별 해설을 곧바로 위원회의 공식 견해로 일반화하지 않는다. **공식 정답표**와 **앱에서 작성한 해설**도 구분한다.

Edge로 원문 본문과 필요한 해설 탭을 열었다. 검색 결과 요약만으로 해설을 확정하지 않았다. 사료와 오래된 교과서에는 역사 해석·연대 차이가 있을 수 있으며, 문제를 푸는 데 불필요한 학설·추정은 덧붙이지 않았다. 주 작업자가 검토했으며 별도의 독립 에이전트 검토는 하지 않았다. 모든 세부 사항을 학술 논문까지 추적한 전수 역사 검증이라는 뜻은 아니다.

## 과거 기록과 확인

- 새 풀이에는 상세 해설과 출처 URL이 기존 기록 형식 안에 저장된다. 기록 형식·동기화 규칙을 바꾸지 않는다.
- 과거에 제출한 풀이와 당시 해설은 보존한다. 해설 추가 전에 푼 문제는 기록이나 채점 화면에서 **추가된 상세 해설 보기**를 펼칠 수 있다.
- 원문·정답이 그대로이므로 1,315개 연습의 식별자를 모두 유지한다. 콘텐츠 검토 해시는 해당 10개만 갱신한다.
- 자동 검사는 해설 누락, 정답표, 원문 이미지, 기존 식별자와 기록 보존을 확인한다. 역사 해석의 정확성을 자동 증명하지 않는다.

국사편찬위원회 자료의 이용 조건은 [공식 저작권 정책](https://www.history.go.kr/contents/contentsPage.do?groupId=000000000571&menuId=000000000572&pageId=000000000213)에 따른다.
