# 과거의 아쉬움 문항 보기 개선

- 대상: `en-session-20260909-wish` 객관식. `I wish I ___ that house last year.`
- 보기: `have bought / bought / had bought / will have bought`. 화면에서는 순서가 섞인다.
- 정답: `had bought`. 실제로 사지 않은 과거의 집을 지금 아쉬워하는 뜻이다.
- 현재완료와 과거완료를 구분하게 하고, 단순과거·미래완료가 이 문맥에 맞지 않는 이유를 해설에 추가했다. 단순히 `last year`가 있으면 과거완료라는 잘못된 규칙을 가르치지 않는다.
- 네 보기 모두 다른 문맥에서 쓰이는 실제 동사 형태다. 주어 `I`에 맞지 않는 `has bought`나 철자가 틀린 형태로 쉽게 소거하도록 만들지 않았다.
- 앞으로 보기는 같은 문법 영역에서 혼동하기 쉬운 형태를 우선한다. 복수 정답이 생기면 보기나 문맥을 조정한다. 정답 판정의 모호함으로 난도를 높이지 않는다.
- 이번 변경은 주 에이전트가 문장 의미와 네 보기를 검토했다. 독립 에이전트 검토를 추가로 시행한 것은 아니다. 자동 검사는 의미적 정확성을 증명하지 않는다.
- 문항·정답·문항 ID는 유지한다. 미완료 문제는 새 보기를 불러오고, 이미 제출한 답과 해설 기록은 보존한다. 카드 수와 복습 간격은 변경하지 않는다.
