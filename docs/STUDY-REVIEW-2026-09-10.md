# 9/10 학습 복습 — 선사 시대부터 삼국 통일까지 (v26)

학습한 범위를 짧게 끊어 복습할 수 있도록 **자체 제작 객관식 40문항**을 추가했다. 공식 기출을 옮긴 문제가 아니다. 각 문항은 4지선다이며 정답 근거, 오답 보기 비교, 기억 연결을 제공한다.

## 사용

첫 화면에서 **9/10 공부 복습 · 8문제씩**을 누른다. 한국사 연습 범위에서 각 묶음 또는 전체 40문제를 고를 수 있다. 같은 기기에서 다시 열면 선택한 묶음과 풀던 문항·채점 화면이 유지된다.

| 묶음 | 범위 | 문항 |
|---|---|---|
| 1 | 선사 시대의 생활·도구·유적 | 01~08 |
| 2 | 고조선·부여·고구려·옥저·동예·삼한 | 09~16 |
| 3 | 고구려의 왕·전쟁, 가야의 중심 | 17~24 |
| 4 | 백제·신라의 왕과 업적 | 25~32 |
| 5 | 부흥 운동·동맹·가야 병합·통일 과정 비교 | 33~40 |

채점한 뒤 **풀이와 기억 연결 보기**를 펼친다. 풀이와 해설 열기의 기존 환산 시간 규칙을 그대로 사용한다. 같은 풀이의 해설은 여러 번 열거나 다른 기기에서 열어도 한 번만 가산한다.

같은 개념의 형제 문항은 기존 10분 간격 정책을 적용한다. 기다리는 문제가 남으면 다른 묶음을 먼저 풀 수 있다. 10분은 앱 운영 정책이며 검증된 최적 암기 간격은 아니다. 묶음의 첫 풀이 개수와 정답 개수를 표시하고 재풀이로 첫 결과를 덮어쓰지 않는다. 이 수치는 공식 한능검 점수로 환산하지 않는다.

## 검토 범위

문항과 해설 전량을 읽어 단일 정답 여부와 반례를 검토했다. 위만 조선의 ‘진’을 한반도 남부의 진으로 명시하고, 족외혼과 형사취수의 방향을 바로잡았다. 유적을 토기나 교역 시설로 바꾸는 식의 터무니없는 오답은 시대·기능·사회 모습의 비교로 고쳤다. 청동기라는 재료와 청동기 시대라는 구분을 혼동하지 않게 문구를 정리했다.

학습 자료를 바탕으로 직접 구성한 문제다. 기관 원문으로 보완한 항목에는 확인 링크를 넣는다. 모든 역사 사실을 기관 원문과 전수 대조했다는 의미는 아니며, 개별 교재의 모든 본문을 포괄하는 문제은행도 아니다. 사진 원본과 개인 Drive 주소는 공개 앱에 포함하지 않는다.
