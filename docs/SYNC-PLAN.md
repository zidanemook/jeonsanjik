# 자동 동기화 연결 계획

2026-09-09 사용자 요구: PC에서 추가한 내용, 어느 기기에서든 푼 기록과 다음 복습일을 자동 동기화한다. JSON 입력·파일 백업·수동 가져오기를 일상 사용자 흐름으로 요구하지 않는다.

현재 상태: 실시간 이벤트 동기화, 오프라인 재전송, 계정별 저장 영역, 최초 기록 이관 코드와 모의 서버 검증을 완료했다. Firebase 프로젝트 설정과 로그인 공급자 연결은 아직 없다. 따라서 현재 배포는 브라우저별 저장이며 자동 동기화가 작동한다고 표시하지 않는다. 실제 서버 연결·보안 규칙 검증·두 기기 검증은 [SYNC-SETUP.md](SYNC-SETUP.md)에 따라 이어간다.

연결 후 목표:

- Google 로그인으로 동일 사용자 식별. 허용한 계정만 자신의 자료에 접근하도록 서버 규칙으로 제한.
- 개인 카드 문서는 안정적인 ID로 관리. 공개 기본 카드는 버전별 콘텐츠로 제공하고 개인 학습 상태와 분리.
- 복습 기록은 고유 이벤트 ID로 저장하고 중복 업로드를 제거. 오프라인 이벤트는 연결 후 전송.
- 기기별 시계 차이·동시에 같은 카드를 푼 충돌·카드 수정 및 삭제를 처리. 전체 localStorage의 단순 마지막 덮어쓰기를 동기화로 사용하지 않음.
- 일정 재계산을 결정적으로 수행하며, 다른 기기에 남은 오래된 기록이 새 기록을 덮지 않도록 함.
- 로그인 전 로컬 기록은 승인된 본인 계정으로 한 번 이관하고 재실행해도 중복하지 않음.
- 두 독립 브라우저, 오프라인 후 재연결, 충돌, 계정 전환·로그아웃 때 데이터 격리를 검증.

Firebase 무료 Spark 범위로 준비한다. 유료 플랜 전환·과금 기능 활성화는 하지 않는다. 프로젝트 ID·웹앱 공개 설정·Google 로그인 및 Firestore 규칙 설정이 연결에 필요하다. Firebase 웹 설정은 비밀번호가 아니며 실제 접근 제어는 인증과 서버 규칙이 담당한다.
