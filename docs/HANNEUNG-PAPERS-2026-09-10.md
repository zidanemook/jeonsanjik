# 한능검 공식 심화 기출 수록 — v23

국사편찬위원회가 공개한 심화 57~79회, 23회분 1,150문항을 원문 이미지로 수록했다. 문제의 사료·사진·지도·보기는 OCR 텍스트로 대체하지 않았다. 63회 42번은 공식 정정된 오류 문항으로, 안내에서 원문을 제공하되 채점·복습 대상에서는 제외한다. 새 채점 가능 문항은 1,149개다.

- [공식 시험 자료실](https://www.historyexam.go.kr/pst/list.do?bbs=dat)
- [시험 요강: 심화 50문항, 1~3점, 3급 60~69점](https://www.historyexam.go.kr/pageLink.do?link=examGuideline)
- 회차별 문제지 다운로드 원본 URL은 `hanneung-data.js`의 `source`에 있고 화면에서도 연결한다. 공개 자료 수집일은 2026-09-10이다.

## 사용 흐름

‘한능검 기출 풀기’를 누르면 한국사 79회로 이동한다. 회차 선택에서 57~79회 또는 기존 핵심 복습을 고를 수 있다. ①~⑤는 원문과 같은 순서를 유지한다. 문제 이미지를 누르면 크게 볼 수 있고, 이미지가 표시되지 않으면 채점을 막고 다시 불러오기 버튼을 제공한다.

첫 풀이 점수는 문제마다 첫 제출 결과에 공식 배점을 적용한 누적값이다. 재풀이로 처음 점수를 덮어쓰지 않는다. 63회 42번은 공식 정답표와 정정 게시물에 따라 전원 정답 처리된 2점으로 합산한다. 분할 학습 결과이므로 실제 80분 모의시험 점수와 구분한다. 3급 이상 기준은 60점이며 연습 결과가 실제 합격을 보장하지 않는다.

정오답·제출한 답·원문 이미지 경로를 기존 불변 학습 기록에 저장한다. 이전 51개 카드의 일정·기록과 기존 166개 예문 식별자·검토 해시는 유지한다. 로그인한 소유자는 기존 Firebase 동기화 경로로 기록을 공유한다. 보안 규칙·권한을 변경하지 않았다. 질문 이미지에 접근할 수 있는 것과 소유자의 학습 기록을 수정할 수 있는 것은 별개다.

상세 해설은 추가하지 않았다. 공식 정답·배점과 상세 해설의 부재를 채점 화면에 표시한다. 학습 과정에서 별도로 확인한 개념을 정리할 수 있으나, 이번 수록을 1,150개 역사 해설의 의미 검증으로 취급하지 않는다.

## 추출·검증

1. 공식 게시물과 첨부를 Edge에서 열어 수집한 PDF 46개를 사용했다. 회차·심화·첨부 구분, 파일 열림·페이지 파싱, 회차당 50개 정답 항목과 배점 합계 100점, ZIP CRC를 확인했다.
2. 문제지 276쪽을 렌더링하고 Windows OCR로 번호 위치만 찾았다. 회차마다 1~50이 원문의 열 읽기 순서대로 정확히 한 번씩 나타나는지 확인했다. 60회 12번은 OCR이 번호 일부를 빠뜨려 원본 이미지를 보고 위치를 보완했다. 본문 문자열은 OCR 결과를 사용하지 않는다.
3. 질문부터 다음 질문 전까지 같은 열을 원본 PDF에서 렌더링했다. 1,150개 WebP는 내용 해시를 파일명에 포함한다. 웹에서 필요한 문제만 불러온다. 이미지 총량은 약 112.2MB지만 초기 페이지에 전량 다운로드하지 않는다.
4. 정답·배점은 별도로 검산한 공식 정답표에서 가져와 [검증 키](hanneung-answer-keys.json)와 대조한다. 60회 26번 표 추출의 분리된 배점은 원본에서 ④·2점으로 확인했다. 63회 42번의 ‘정답 없음’은 `0`으로 보존한다.
5. 원문 이미지 예시와 모바일 표시를 직접 확인했다. 모든 문항의 역사적 명제·보기 의미를 새로 검토한 것은 아니다. 이미지 해시는 파일 변경을 잡으며, 문항의 의미적 정확성을 증명하지 않는다.

## 검증 결과

- Node 검사 11개 통과: 기존 일정·학습·동기화·배포 설정·문제 회전·기록·콘텐츠·시간 적립 검사와 한능검 원문/공식 정답/배점/고정 보기/오류 처리 검사.
- Edge 격리 세션: v22의 기존 일정·기록 유지, 회차별 원문 이미지와 5지선다, 오답·정답, 새로고침, 첫 점수 보존, 두 브라우저 컨텍스트의 동기화 병합, 기록 속 원문 재표시, 오류 문항 안내, 캐시한 이미지 오프라인 사용, 미수신 이미지 채점 차단·재시도, 영어 범위 유지, 412px 화면 가로 넘침 없음.
- 동기화 검사는 기존 클라이언트·모의 서버 검사와 격리 컨텍스트 병합 검사로 수행했다. 사용자의 운영 학습 기록에 테스트 답안을 쓰지 않았다. 물리적인 갤럭시탭 두 대에서의 새 시험은 수행하지 않았다.

앱은 기존 카드 51개+새 기출 카드 1,149개=1,200개, 채점 가능 연습 166+1,149=1,315개다. 한국사는 기존 8개+원문 1,149개=1,157개이며 오류 참고 문항 1개는 별도로 제공한다.
