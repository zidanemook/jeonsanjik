## 기능

2026-09-09 업데이트: 정답 공개 전에 ‘떠올렸어요 / 일부만 떠올랐어요 / 모르겠어요’를 선택합니다. 공개 후 자기 답과 비교해 평가하세요. 부분 회상은 완전 정답으로, 모름은 성공으로 기록할 수 없습니다. 틀림·불완전은 5분 뒤 재학습하며, 당일 재학습에 성공해도 다음 날 다시 복습합니다. 5분은 초기 운영값이며 과학적으로 유일한 최적 간격이라는 뜻은 아닙니다.

‘날짜를 넘긴 첫 복습 정답률’은 이 업데이트 이후 수집한 회상 기록 중, 이전 날짜의 복습 기록이 있는 카드의 그날 첫 평가를 집계합니다. 첫 학습·당일 재시도·과거에 회상 여부가 없던 기록은 제외합니다. 정답률은 자기평가 기반이며 시험 예상 점수가 아닙니다. 새로고침해도 공개 중인 답과 재학습 대기가 유지됩니다. ‘다시 학습’은 대기·진행 중 답 공개를 초기화하지만 과거 기록은 남깁니다.

연구 보고서: [복습·암기 방법의 근거와 앱 적용안](docs/LEARNING-SCIENCE-REVIEW.md). 연구 제안 기능은 현재 구현 기능과 구분되어 있습니다.

- 카드 추가·편집·검색, 정답 확인과 복습 기록
- 정답·헷갈림·오답에 따라 다음 복습 간격 조정
- AI와 별도 대화로 만든 JSON 문제 가져오기

현재 데이터는 기기별 브라우저 localStorage에 저장합니다. 로그인과 자동 기기 간 동기화는 아직 구현하지 않았습니다. 브라우저 데이터 삭제에 대비해 백업을 보관하세요. GitHub에는 개인 학습 기록을 올리지 않습니다.

## 실행

`python -m http.server 8766 --bind 127.0.0.1`

PC에서 http://localhost:8766 에 접속합니다. 설치·오프라인 기능은 HTTPS 또는 localhost가 필요합니다. 실제 Android 설치 검증은 아직 남아 있습니다.
